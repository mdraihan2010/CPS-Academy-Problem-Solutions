# 💯 CPS Academy Problem Solutions

This repository contains my solutions to **100 beginner-level C++ programming problems** collected from different online judges. These problems helped me strengthen my programming fundamentals, problem-solving skills, and algorithmic thinking.

---

## 📚 About

This repository is part of my Competitive Programming journey.

The solutions are written in **C++** and cover various beginner topics such as:

- Input & Output
- Variables
- Conditions
- Loops
- Arrays
- Strings
- Functions
- Basic Mathematics
- Searching
- Sorting
- Problem Solving Techniques
