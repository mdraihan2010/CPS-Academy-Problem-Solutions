# 🚀 CPS Academy Problem Solutions

Welcome to my **CPS Academy Problem Solutions** repository.

This repository contains my solutions to the **CPS Academy Competitive Programming Course**, where I learned and practiced Competitive Programming from the fundamentals to problem-solving techniques using **C and C++**.

Each contest focuses on a specific topic, and all solutions are organized in separate folders with detailed `README.md` files.
